# Bench fonts

`Roboto-Regular.msdf.{json,png}` and `Roboto-Bold.msdf.{json,png}` are MSDF
atlases of **Roboto** (Christian Robertson, Google), the same files as
solid-demo-app's `public/fonts`. The benchmark app loads them as the families
`Roboto` and `Roboto700` (`bench/src/main.tsx`).
