# Test fonts

`Lato-Regular.msdf.{json,png}` is an MSDF atlas of **Lato** (Łukasz Dziedzic),
the same files as solid-demo-app's `public/fonts`. The WebGL tests load it as
`Lato` and `LatoLate` (`tests/webgl/setup.ts`).
